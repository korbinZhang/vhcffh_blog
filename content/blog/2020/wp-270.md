# mysql 新建用户



一、新建用户

    CREATE USER 'username'@'host' IDENTIFIED BY 'password';

username:用户名

host:允许在那些ip登录(%)

password:密码

\'username\'和\@和\'host\'之间没有空格

二、授权

    GRANT privileges ON databasename.tablename TO 'username'@'host';
    FLUSH PRIVILEGES;

privileges:具体权限`SELECT`,`INSERT`,`UPDATE`,`DELETE`,`CREATE`,`DROP`(`ALL`)

databasename:数据库名(\*)

tablename:表名(\*)

三、撤权

与授权相似`GRANT`-\>`REVOKE`,`TO`-\>`FROM`

```
REVOKE privileges ON databasename.tablename FROM 'username'@'host';
FLUSH PRIVILEGES;
```

privileges:具体权限`SELECT`,`INSERT`,`UPDATE`,`DELETE`,`CREATE`,`DROP`(`ALL`)

databasename:数据库名(\*)

tablename:表名(\*)
