## 第一部分 经济学基础

### 第1章 社会主义基本经济制度

**社会主义基本经济制度的内涵**
- 公有制为主体、多种所有制经济共同发展
- 按劳分配为主体、多种分配方式并存
- 社会主义市场经济体制

**社会主义所有制的基本内涵**
- **公有制经济**：国有经济、集体经济、混合所有制经济中的国有成分和集体成分
- **非公有制经济**：个体经济、私营经济、外资经济
- **两个毫不动摇**：毫不动摇巩固和发展公有制经济，毫不动摇鼓励、支持、引导非公有制经济发展

**社会主义收入分配制度的内涵**
- **按劳分配**：公有制经济中，按劳动者提供的劳动数量和质量分配
- **按要素分配**：按资本、土地、知识、技术、管理、数据等要素贡献分配
- **再分配调节**：税收、社会保障、转移支付等手段调节收入差距
- **第三次分配**：慈善、捐赠等自愿方式

**社会主义市场经济体制的内涵**
- 市场在资源配置中起决定性作用
- 更好发挥政府作用
- 有效市场与有为政府相结合

### 第2章 市场需求、供给与均衡价格

**市场需求的含义与影响因素**
- **需求**：消费者在一定时期内，在各种可能的价格水平上愿意而且能够购买的该种商品的数量
- **需求规律**：价格上升，需求减少；价格下降，需求增加（向右下方倾斜）
- **影响因素**：商品价格、消费者收入、相关商品价格（替代品、互补品）、消费者偏好、预期

**市场供给的含义与影响因素**
- **供给**：生产者在一定时期内，在各种可能的价格水平上愿意而且能够提供的该种商品的数量
- **供给规律**：价格上升，供给增加；价格下降，供给减少（向右上方倾斜）
- **影响因素**：商品价格、生产成本、生产技术、相关商品价格、生产者预期

**均衡价格的形成机制**
- **均衡价格**：需求价格 = 供给价格时的市场价格
- **均衡数量**：均衡价格下的交易量
- **形成过程**：供过于求→价格下降→供给减少、需求增加→均衡；供不应求→价格上升→供给增加、需求减少→均衡

**运用均衡价格模型分析市场关系**
- 需求变动（曲线平移）vs 需求量变动（沿曲线移动）
- 供给变动（曲线平移）vs 供给量变动（沿曲线移动）
- 供求同时变动的影响

**市场价格形成的基础**
- 价值决定价格
- 供求影响价格
- 价格围绕价值上下波动

### 第3章 生产和成本理论

**生产理论**
- **生产函数**：Q = f(L, K)，表示投入与产出之间的技术关系
- **短期生产函数**：至少一种要素固定不变，研究可变要素的边际产量
  - 总产量（TP）、平均产量（AP）、边际产量（MP）
  - 边际报酬递减规律：其他要素不变，连续增加某种要素，边际产量先增后减
- **长期生产函数**：所有要素都可变，研究规模报酬
  - 规模报酬递增、不变、递减

**生产者的组织形式**
- 个人业主制：个人出资、个人经营、个人收益、个人承担风险
- 合伙制：两个以上合伙人共同出资、共同经营、共担风险
- 公司制：有限责任公司、股份有限公司，独立法人、有限责任

**企业形成的相关理论**
- **交易成本理论**（科斯）：企业是为了节约市场交易成本
- **企业的本质**：替代市场的资源配置方式

**成本理论**
- **成本函数**：C = f(Q)，表示成本与产量之间的关系
- **短期成本**：
  - 固定成本（FC）：不随产量变动
  - 可变成本（VC）：随产量变动
  - 总成本（TC）= FC + VC
  - 平均成本（AC）= TC/Q = AFC + AVC
  - 边际成本（MC）= ΔTC/ΔQ

**短期成本曲线特征**
- MC曲线先降后升，呈U型
- MC穿过AC和AVC的最低点
- AC = AVC + AFC，两者差距随产量增加而缩小

### 第4章 市场结构理论

**市场结构的分类及其依据**
- **划分依据**：市场上生产者（卖者）和消费者（买者）的数量、产品差别程度、进入壁垒
- **四种市场类型**：完全竞争、垄断竞争、寡头垄断、完全垄断

**完全竞争市场**
- 特征：大量买者和卖者、产品同质、自由进出、信息完全
- 需求曲线：水平线（P = MR = AR）
- 均衡条件：MR = MC，P = MC
- 效率：资源配置最优，消费者剩余最大

**垄断竞争市场**
- 特征：较多卖者、产品有差别、进出较容易
- 需求曲线：向右下方倾斜
- 均衡条件：MR = MC
- 例子：零售业、餐饮业

**寡头垄断市场**
- 特征：少数几个卖者控制市场、产品可有差别也可无差别、进入壁垒高
- 模型：古诺模型、伯特兰模型、斯塔克尔伯格模型
- 例子：汽车、钢铁、电信

**完全垄断市场**
- 特征：唯一卖者、无相近替代品、进入壁垒极高
- 需求曲线：向右下方倾斜
- 价格歧视：一级（完全）、二级（数量）、三级（市场分割）
- 例子：公用事业

**市场结构和生产者决策理论**
- 不同市场结构下，生产者根据MR = MC原则决定产量和价格
- 完全竞争：P = MC，效率最高
- 垄断：P > MC，存在无谓损失

### 第5章 生产要素市场理论

**生产者使用生产要素的原则**
- 利润最大化原则：边际收益产品（MRP）= 边际要素成本（MFC）
- MRP = MP × MR，表示增加一单位要素带来的收益增加
- 完全竞争下：MRP = VMP（边际产品价值）= MP × P

**生产要素市场理论基本内容**
- 生产要素：劳动、资本、土地、企业家才能
- 要素需求：引致需求，由产品市场需求决定
- 要素供给：劳动供给、资本供给、土地供给

**劳动供给曲线**
- 向后弯曲的劳动供给曲线
- 工资较低时：替代效应 > 收入效应，工资上升，劳动供给增加
- 工资较高时：收入效应 > 替代效应，工资上升，劳动供给减少

**均衡工资决定方式**
- 劳动市场均衡：劳动需求 = 劳动供给
- 均衡工资由劳动市场的供求关系决定
- 工资差别：补偿性工资差别、竞争性工资差别、垄断性工资差别

### 第6章 市场失灵和政府的干预

**资源最优配置的标准**
- 帕累托最优：不可能通过重新配置资源，使某些人的状况变好而不使任何人的状况变坏
- 帕累托改进：通过重新配置资源，使某些人的状况变好而不使任何人的状况变坏

**帕累托最优状态的条件**
- 交换最优：任意两个消费者的边际替代率相等
- 生产最优：任意两个生产者的边际技术替代率相等
- 产品混合最优：边际替代率 = 边际转换率

**市场失灵理论**

**市场垄断**
- 垄断导致产量低于竞争水平，价格高于竞争水平
- 造成无谓损失，降低资源配置效率
- 政府干预：反垄断法、价格管制

**外部性**
- **正外部性**：社会收益 > 私人收益，如教育、研发
  - 市场供给不足
  - 政府干预：补贴、专利保护
- **负外部性**：社会成本 > 私人成本，如污染
  - 市场供给过多
  - 政府干预：征税、排污权交易、管制

**公共物品**
- 特征：非竞争性、非排他性
- 纯公共物品：国防、灯塔
- 准公共物品：收费公路、教育
- 搭便车问题：市场无法有效提供
- 政府干预：政府直接提供、政府生产私人经营

**信息不对称**
- **逆向选择**：交易前信息不对称，劣币驱逐良币
  - 例子：二手车市场、保险市场
  - 解决：信号传递、信息甄别
- **道德风险**：交易后信息不对称，一方行为损害另一方利益
  - 例子：保险后的道德风险
  - 解决：激励相容、监督

**政府干预**
- **干预方式**：
  - 法律手段：反垄断法、消费者权益保护法
  - 行政手段：许可证、配额
  - 经济手段：税收、补贴
- **政府失灵**：
  - 信息不完全
  - 官僚主义
  - 寻租行为
  - 政策时滞

### 第7章 国民收入核算和简单的宏观经济模型

**国民收入核算**
- **国内生产总值（GDP）**：一国（地区）在一定时期内生产的所有最终产品和服务的市场价值总和
- **国民总收入（GNI）**：GDP + 来自国外的要素收入净额
- **GDP核算方法**：
  - 生产法：GDP = 总产出 - 中间投入
  - 收入法：GDP = 劳动者报酬 + 生产税净额 + 固定资产折旧 + 营业盈余
  - 支出法：GDP = C + I + G + (X - M)

**宏观经济基本理论**
- **消费（C）**：C = a + bY，a为自发性消费，b为边际消费倾向
- **储蓄（S）**：S = Y - C = -a + (1-b)Y
- **投资（I）**：I = e - dr，e为自发性投资，d为投资对利率的敏感度
- **总需求（AD）**：AD = C + I + G + (X - M)
- **总供给（AS）**：短期AS向右上方倾斜，长期AS垂直

**消费、储蓄、投资与国民收入之间的关系**
- 两部门经济：Y = C + I，S = I
- 三部门经济：Y = C + I + G，S + T = I + G
- 四部门经济：Y = C + I + G + (X - M)，S + T + M = I + G + X
- 乘数效应：投资乘数 = 1/(1-MPC) = 1/MPS

### 第8章 经济增长和经济发展理论

**经济增长的基本原理**
- 经济增长：一个国家或地区在一定时期内生产的产品和劳务总量的增加
- 衡量指标：GDP增长率、人均GDP增长率
- 经济增长源泉：劳动、资本、技术进步

**经济发展的基本原理**
- 经济发展：不仅包括经济增长，还包括经济结构优化、生活质量提高、社会进步
- 衡量指标：人类发展指数（HDI）、基尼系数、幸福指数

**经济增长的影响因素**
- 制度因素：产权制度、市场制度
- 资源因素：自然资源、人力资源
- 技术因素：技术创新、技术扩散
- 结构因素：产业结构、区域结构

**我国经济新发展理念**
- **创新**：解决发展动力问题
- **协调**：解决发展不平衡问题
- **绿色**：解决人与自然和谐问题
- **开放**：解决发展内外联动问题
- **共享**：解决社会公平正义问题

**新发展阶段**
- 全面建成小康社会后，开启全面建设社会主义现代化国家新征程
- 2035年基本实现社会主义现代化
- 本世纪中叶建成富强民主文明和谐美丽的社会主义现代化强国

**新发展格局**
- 以国内大循环为主体
- 国内国际双循环相互促进
- 扩大内需为战略基点

**高质量发展的内涵和特征**
- 从"有没有"转向"好不好"
- 效率变革、质量变革、动力变革
- 创新成为第一动力

**中国式现代化的含义和特征**
- 人口规模巨大的现代化
- 全体人民共同富裕的现代化
- 物质文明和精神文明相协调的现代化
- 人与自然和谐共生的现代化
- 走和平发展道路的现代化

### 第9章 价格总水平和就业、失业

**价格总水平**
- **含义**：一个国家或地区在一定时期内全社会各类商品和服务价格变动的平均趋势
- **衡量指标**：CPI（消费者价格指数）、PPI（生产者价格指数）、GDP平减指数
- **CPI**：反映居民家庭购买消费商品和服务价格变动
- **PPI**：反映工业企业产品出厂价格变动

**就业**
- **含义**：在法定劳动年龄内，有劳动能力，从事一定社会劳动并取得劳动报酬或经营收入
- **衡量指标**：就业率、失业率、劳动参与率
- **充分就业**：消除非自愿失业，允许摩擦性失业和结构性失业存在

**失业**
- **含义**：在法定劳动年龄内，有劳动能力，有就业愿望，但没有工作
- **类型**：
  - 摩擦性失业：劳动力市场信息不对称，求职过程中的短期失业
  - 结构性失业：经济结构变化，劳动者技能与岗位需求不匹配
  - 周期性失业：经济衰退，总需求不足导致的失业
  - 季节性失业：某些行业的季节性波动
- **自然失业率**：摩擦性失业 + 结构性失业

**就业、失业和经济增长的相互关系**
- **奥肯定律**：GDP每下降2个百分点，失业率上升1个百分点
- **菲利普斯曲线**：通货膨胀率与失业率之间的替代关系
  - 短期：向右下方倾斜，通胀与失业负相关
  - 长期：垂直，不存在替代关系

**就业、失业和价格总水平的相互关系**
- 失业率高 → 总需求不足 → 物价下降
- 失业率低 → 总需求旺盛 → 物价上升
- 滞胀：高通胀与高失业并存

**宏观经济治理的内涵与特征**
- 内涵：运用多种政策工具，实现经济稳定增长
- 特征：系统性、协同性、前瞻性
- 政策工具：财政政策、货币政策、产业政策、就业政策

### 第10章 国际贸易理论和政策

**国际贸易基本理论**
- **绝对优势理论**（亚当·斯密）：各国生产并出口具有绝对优势的产品
- **比较优势理论**（李嘉图）：各国生产并出口具有比较优势（机会成本低）的产品
- **赫克歇尔-俄林理论**（要素禀赋理论）：各国出口密集使用其丰富要素的产品
- **规模经济理论**：大规模生产降低成本，促进贸易
- **产品生命周期理论**：产品在不同阶段，比较优势发生转移

**影响国际贸易的主要因素**
- 生产要素禀赋
- 技术水平
- 需求偏好
- 规模经济
- 政府政策
- 汇率水平

**政府对进出口贸易的调控和干预**
- **关税**：从价税、从量税、混合税
- **非关税壁垒**：配额、许可证、技术性贸易壁垒、绿色壁垒
- **出口促进**：出口补贴、出口退税、出口信贷

**建设更高水平对外开放新体制**
- 推进贸易和投资自由化便利化
- 建设自由贸易试验区和海南自由贸易港
- 推动共建"一带一路"高质量发展
- 积极参与全球经济治理体系改革
- 构建面向全球的高标准自由贸易区网络

## 第二部分 财政税收

### 第11章 公共物品与财政职能

**公共物品及其特征**
- **公共物品**：增加一个人消费不会减少其他人可用数量的物品
- **特征**：
  - 非竞争性：一个人的消费不影响其他人的消费
  - 非排他性：无法排除不付费者消费
- **纯公共物品**：完全非竞争、完全非排他，如国防、灯塔
- **准公共物品**：具有部分非竞争或非排他性，如教育、医疗

**财政的基本职能**
- **资源配置职能**：通过财政收支，引导资源流向
- **收入分配职能**：通过税收、转移支付，调节收入差距
- **经济稳定和发展职能**：通过财政政策，平抑经济波动

**市场与政府经济活动范围**
- **市场有效领域**：私人物品、竞争性行业
- **政府必要领域**：公共物品、外部性、自然垄断、信息不对称
- **政府与市场的关系**：市场决定性作用，政府更好发挥作用

### 第12章 财政支出

**财政支出的类型**
- **按功能分类**：一般公共服务、外交、国防、教育、科学技术等
- **按经济性质分类**：购买性支出、转移性支出

**衡量财政支出规模的指标**
- 财政支出总额
- 财政支出占GDP比重
- 财政支出增长率

**财政支出规模增长的理论解释**
- **瓦格纳法则**：随着人均收入提高，财政支出占GDP比重上升
- **皮考克和魏斯曼的梯度渐进增长理论**：财政支出增长呈阶梯状
- **马斯格雷夫的经济发展阶段增长理论**：不同发展阶段，支出重点不同
- **鲍莫尔的非均衡增长模型**：公共部门生产率低于私人部门，导致支出增长

**财政支出规模增长的影响因素**
- 经济发展水平
- 经济体制
- 政府职能转变
- 社会需求变化

**财政支出效益分析方法**
- **成本-效益分析法**：适用于经济性项目
- **最低费用选择法**：适用于军事、政治等项目
- **公共劳务收费法**：适用于可以收费的公共劳务

**购买性支出**
- **政府消费性支出**：行政管理费、文教科学卫生事业费
- **政府投资性支出**：基础设施投资、农业投资

**转移性支出**
- **社会保障支出**：养老保险、医疗保险、失业保险
- **财政补贴**：价格补贴、企业亏损补贴
- **捐赠支出**：对外捐赠、对内捐赠

**购买性支出和转移性支出的异同**
- **相同点**：都是财政支出形式
- **不同点**：
  - 购买性支出：有偿性、等价性，直接影响生产和就业
  - 转移性支出：无偿性、单方面转移，直接影响收入分配

### 第13章 财政收入

**财政收入及其分类**
- **按形式分类**：税收收入、社会保险基金收入、非税收入、贷款转贷回收本金收入、债务收入
- **按政府级次分类**：中央财政收入、地方财政收入
- **按经济性质分类**：经常性收入、资本性收入

**财政集中度**
- 财政集中度 = 财政收入 / GDP
- 反映政府集中财力的程度

**宏观税负**
- 宏观税负 = 税收收入 / GDP
- 小口径：仅税收收入
- 中口径：税收收入 + 社会保障缴费
- 大口径：全部政府收入

**税收的基本特征**
- **强制性**：凭借政治权力征收
- **无偿性**：不直接向纳税人支付报酬
- **固定性**：按预定标准征收

**税收的职能**
- 财政职能：筹集财政收入
- 经济职能：调节经济运行
- 监督职能：反映经济运行状况

**税负转嫁的方式和原理**
- **前转**：提高商品价格，转嫁给消费者
- **后转**：压低要素价格，转嫁给要素提供者
- **混转**：同时前转和后转
- **旁转**：转嫁给其他相关方
- **消转**：通过提高效率消化税负

**国债的种类**
- **按期限**：短期国债、中期国债、长期国债
- **按资金用途**：赤字国债、建设国债、战争国债、特种国债
- **按流通与否**：可转让国债、不可转让国债

**国债的政策功能**
- 弥补财政赤字
- 筹集建设资金
- 调节宏观经济

**国债的负担与限度**
- 国债负担：政府偿债压力
- 国债限度：国债余额 / GDP（国际警戒线60%）

**国债市场和功能**
- 发行市场：一级市场
- 流通市场：二级市场
- 功能：融资、价格发现、货币政策操作

**我国政府债务管理制度**
- 实行余额管理
- 分类管理：一般债务、专项债务
- 风险预警和应急处置机制

### 第14章 税收制度

**税制各要素**
- **纳税人**：直接负有纳税义务的单位和个人

- **税率**：比例税率、累进税率、定额税率
- **纳税环节**：生产、流通、分配各环节
- **纳税期限**：纳税义务发生时间、申报期限、缴库期限
- **减免税**：起征点、免征额、减税、免税

**税收分类**
- **按课税对象**：流转税、所得税、财产税、资源税、行为税
- **按税负能否转嫁**：直接税、间接税
- **按税收管理权限**：中央税、地方税、中央地方共享税

**我国现行税收法律制度**
- 18个税种：增值税、消费税、企业所得税、个人所得税、资源税、城市维护建设税、房产税、印花税、城镇土地使用税、土地增值税、车船税、船舶吨税、车辆购置税、关税、耕地占用税、契税、环境保护税、烟叶税

**增值税**
- **特点**：不重复征税、税负转嫁
- **纳税人**：一般纳税人、小规模纳税人
- **税率**：13%、9%、6%、零税率
- **计税方法**：一般计税方法、简易计税方法
- **应纳税额**：销项税额 - 进项税额

**消费税**
- **特点**：选择性征收、单环节征收
- **征收范围**：烟、酒、化妆品、贵重首饰、鞭炮、成品油、小汽车等15类
- **税率**：比例税率、定额税率
- **计税方法**：从价定率、从量定额、复合计税

**企业所得税**
- **纳税人**：居民企业、非居民企业
- **税率**：25%（基本税率）、20%（小型微利企业）、15%（高新技术企业）
- **应纳税所得额**：收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 允许弥补的以前年度亏损

**个人所得税**
- **纳税人**：居民个人、非居民个人
- **征税范围**：工资薪金、劳务报酬、稿酬、特许权使用费、经营所得、利息股息红利、财产租赁、财产转让、偶然所得
- **税率**：综合所得3%-45%超额累进税率，经营所得5%-35%超额累进税率，其他20%比例税率
- **专项附加扣除**：子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人、3岁以下婴幼儿照护

**房产税**
- **纳税人**：产权所有人
- **征税范围**：城市、县城、建制镇、工矿区
- **税率**：从价计征1.2%，从租计征12%（个人出租住房4%）

**契税**
- **纳税人**：承受土地、房屋权属的单位和个人
- **税率**：3%-5%
- **计税依据**：成交价格、市场价格

**车船税**
- **纳税人**：车辆、船舶的所有人或者管理人
- **计税依据**：辆、整备质量吨位、净吨位、艇身长度
- **税率**：定额税率

## 第三部分 货币与金融

### 第18章 货币供求与货币均衡

**基础概念**
- **货币需求**：经济主体在既定收入和价格水平下，愿意以货币形式持有资产的需求
- **货币需求量**：在一定时期内，社会各经济主体愿以货币形式持有的数量
- **社会融资规模**：一定时期内实体经济从金融体系获得的资金额
- **通货膨胀**：物价总水平持续上涨的现象
- **数字货币**：以数字形式存在的货币，包括法定数字货币和私人数字货币

**货币需求理论**
- **费雪方程式**：MV = PT，货币需求仅由交易量决定
- **剑桥方程式**：Md = kPY，强调货币作为资产的功能
- **凯恩斯流动性偏好理论**：交易动机、预防动机、投机动机
- **弗里德曼现代货币数量论**：货币需求受多种因素影响，相对稳定

**货币供给机制**
- 基础货币 = 流通中现金 + 准备金
- 货币供给量 = 基础货币 × 货币乘数
- 货币乘数 = (1 + c) / (r + e + c)

**货币均衡的基本原理**
- 货币均衡：货币供给 = 货币需求
- 失衡表现：通货膨胀（供过于求）、通货紧缩（供不应求）
- 实现机制：利率机制、价格机制、收入机制

### 第24章 描述统计

**数据特征测度**
- 用统计指标对数据特征进行概括和描述

**集中趋势测度**
- **均值**：算术平均数、几何平均数
- **中位数**：排序后位于中间位置的值
- **众数**：出现次数最多的值
- **适用场景**：
  - 对称分布：均值、中位数、众数相等
  - 偏态分布：中位数更稳健

**离散趋势测度**
- **极差**：最大值 - 最小值
- **方差**：各数据与均值离差平方的平均数
- **标准差**：方差的平方根
- **离散系数**：标准差 / 均值，用于比较不同量纲数据

**分布形态测度**
- **偏态**：数据分布的不对称性
  - 正偏（右偏）：均值 > 中位数 > 众数
  - 负偏（左偏）：均值 < 中位数 < 众数
- **峰态**：数据分布的陡峭程度
  - 尖峰：峰度系数 > 0
  - 平峰：峰度系数 < 0

**变量间相关关系测度**
- **相关系数**：衡量两个变量线性相关程度
  - r ∈ [-1, 1]
  - |r| > 0.8：高度相关
  - 0.5 < |r| ≤ 0.8：中度相关
  - |r| ≤ 0.5：低度相关

### 第25章 抽样调查

**抽样方法**
- **概率抽样**：每个单位被抽中的概率已知且不为零
  - 简单随机抽样、分层抽样、系统抽样、整群抽样
- **非概率抽样**：不依据概率原理
  - 判断抽样、方便抽样、自愿抽样、配额抽样

**抽样调查步骤**
- 确定调查目的和总体
- 选择抽样方法
- 确定样本量
- 实施抽样
- 数据收集与处理
- 推断总体特征

**误差来源**
- **抽样误差**：由抽样随机性引起，不可避免但可控制
- **非抽样误差**：调查过程中产生，如登记误差、无回答误差

**常用概率抽样方法**
- **简单随机抽样**：每个单位等概率被抽中
- **分层抽样**：先分层，再从各层随机抽样
- **系统抽样**：按固定间隔抽取
- **整群抽样**：先抽群，再对选中群进行全面调查

**估计量的性质**
- **无偏性**：估计量的期望等于总体参数
- **有效性**：方差最小
- **一致性**：样本量增大时，估计量收敛于总体参数

**样本量计算**
- 估计总体均值时：n = (Z²σ²) / E²
- 估计总体比例时：n = (Z²p(1-p)) / E²

**样本量影响因素**
- 总体方差：方差越大，样本量越大
- 允许误差：误差越小，样本量越大
- 置信水平：水平越高，样本量越大

### 第26章 回归分析

**回归模型**
- 描述因变量与自变量之间关系的数学模型
- 一元回归：Y = β0 + β1X + ε
- 多元回归：Y = β0 + β1X1 + β2X2 + ... + βkXk + ε

**回归方程**
- 总体回归方程：E(Y|X) = β0 + β1X
- 样本回归方程：Ŷ = b0 + b1X

**回归系数**
- β1：X每变动一个单位，Y平均变动β1个单位
- 经济意义：边际效应、弹性

**最小二乘法**
- **原理**：使残差平方和最小
- **估计方法**：
  - b1 = Σ(Xi-X̄)(Yi-Ȳ) / Σ(Xi-X̄)²
  - b0 = Ȳ - b1X̄

**回归系数分析**
- 显著性检验：t检验
- 置信区间：b1 ± t(α/2) × SE(b1)

**决定系数**
- R² = SSR/SST = 1 - SSE/SST
- 反映回归直线对数据的拟合程度
- R² ∈ [0, 1]，越接近1拟合越好

**回归模型检验**
- **拟合优度检验**：R²
- **显著性检验**：F检验（整体）、t检验（单个）
- **残差分析**：检验模型假设是否满足

### 第27章 时间序列分析

**时间序列的分类**
- **按形式分**：绝对数时间序列、相对数时间序列、平均数时间序列
- **按性质分**：平稳时间序列、非平稳时间序列

**时间序列的分解**
- **构成要素**：
  - 趋势（T）：长期趋势
  - 季节变动（S）：周期性波动
  - 循环波动（C）：非固定周期波动
  - 不规则波动（I）：随机波动
- **分解模型**：
  - 加法模型：Y = T + S + C + I
  - 乘法模型：Y = T × S × C × I

**时间序列的水平分析**
- **发展水平**：报告期水平、基期水平、平均发展水平
- **增长量**：逐期增长量、累计增长量
- **平均增长量**：累计增长量 / 时间序列项数

**时间序列的速度分析**
- **发展速度**：报告期水平 / 基期水平
  - 定基发展速度、环比发展速度
- **增长速度**：增长量 / 基期水平
- **平均发展速度**：几何平均法、方程式法
- **平均增长速度**：平均发展速度 - 1

**时间序列预测程序**
- 绘制时间序列图
- 选择预测方法
- 建立预测模型
- 进行预测
- 评估预测精度

**平稳时间序列的平滑预测法**
- **简单平均法**：Y(t+1) = (Y1 + Y2 + ... + Yt) / t
- **移动平均法**：Y(t+1) = (Yt-k+1 + ... + Yt) / k
- **指数平滑法**：
  - 一次指数平滑：Ft+1 = αYt + (1-α)Ft
  - α为平滑系数，0 < α < 1

## 第五部分 会计

### 第28章 会计概论

**会计的基本概念**
- 会计是以货币为主要计量单位，对经济活动进行确认、计量、记录和报告的过程

**会计的目标**
- 向财务报告使用者提供决策有用的信息
- 反映企业管理层受托责任履行情况

**会计要素**
- **资产**：企业过去的交易或事项形成的、由企业拥有或控制的、预期会给企业带来经济利益的资源
- **负债**：企业过去的交易或事项形成的、预期会导致经济利益流出企业的现时义务
- **所有者权益**：资产扣除负债后，由所有者享有的剩余权益
- **收入**：企业在日常活动中形成的、会导致所有者权益增加的、与所有者投入资本无关的经济利益的总流入
- **费用**：企业在日常活动中发生的、会导致所有者权益减少的、与向所有者分配利润无关的经济利益的总流出
- **利润**：企业在一定会计期间的经营成果

**会计要素的确认和计量原则**
- **确认原则**：符合要素定义、可计量、相关信息可靠
- **计量属性**：历史成本、重置成本、可变现净值、现值、公允价值

**会计的基本前提**
- **会计主体**：会计确认、计量和报告的空间范围
- **持续经营**：假定企业在可预见的将来会持续经营下去
- **会计分期**：将持续经营期间划分为若干期间
- **货币计量**：以货币作为主要计量单位

**会计信息质量要求**
- 可靠性、相关性、可理解性、可比性
- 实质重于形式、重要性、谨慎性、及时性

**会计法规的构成**
- 会计法律：《会计法》
- 会计行政法规：《企业财务会计报告条例》
- 会计部门规章：《企业会计准则》
- 地方性会计法规

### 第29章 会计循环

**会计确认与计量**
- **会计确认**：将符合会计要素定义的项目正式记入账簿
- **会计计量**：确定会计要素金额的过程
- **会计计量属性**：历史成本、重置成本、可变现净值、现值、公允价值

**会计记录**

- **复式记账法**：对每笔业务在两个或两个以上相互联系的账户中记录
- **借贷记账法**：以"借""贷"为记账符号，"有借必有贷，借贷必相等"

**账务处理程序**
- 记账凭证账务处理程序
- 汇总记账凭证账务处理程序
- 科目汇总表账务处理程序

**会计循环主要环节**

**财务会计报告**
- **概念**：反映企业特定日期财务状况和特定期间经营成果、现金流量的文件
- **内容**：资产负债表、利润表、现金流量表、所有者权益变动表、附注

**会计报表分类**
- 按反映内容：静态报表、动态报表
- 按编制时间：月报、季报、年报
- 按编制主体：个别报表、合并报表

### 第30章 会计报表

**会计报表基础**
- **概念**：根据日常会计核算资料，定期编制的反映企业财务状况、经营成果和现金流量的书面文件
- **目标**：提供决策有用的信息
- **编制要求**：真实可靠、相关可比、清晰明了、编报及时
- **编制前准备**：期末账项调整、对账、财产清查

**资产负债表**
- **作用**：反映企业特定日期的财务状况
- **格式**：账户式（左右结构）
- **内容**：资产 = 负债 + 所有者权益
- **编制方法**：根据总账或明细账余额填列

**利润表**
- **作用**：反映企业一定期间的经营成果
- **格式**：多步式
- **内容**：收入 - 费用 = 利润
- **编制方法**：根据损益类账户发生额填列

**现金流量表**
- **作用**：反映企业一定期间现金和现金等价物流入和流出
- **格式**：报告式
- **内容**：经营活动、投资活动、筹资活动现金流量
- **编制方法**：直接法、间接法

**报表项目填列方法**
- 直接根据总账余额填列
- 根据几个总账余额计算填列
- 根据明细账余额计算填列
- 根据总账和明细账余额计算填列
- 根据有关账户余额减去备抵账户余额后的净额填列

**会计报表附注**
- **概念**：对报表中列示项目的文字描述或明细资料
- **内容**：企业基本情况、财务报表编制基础、重要会计政策和估计、报表项目说明等

### 第31章 财务报表分析

**财务报表分析的意义和内容**
- **意义**：评价企业财务状况、经营成果，为决策提供依据
- **内容**：偿债能力分析、营运能力分析、盈利能力分析

**财务报表分析的基本方法**
- **比率分析法**：计算各种财务比率
- **比较分析法**：与历史、同行、预算比较
- **因素分析法**：分析各因素对指标的影响

**偿债能力指标**
- **短期偿债能力**：
  - 流动比率 = 流动资产 / 流动负债（一般2:1为宜）
  - 速动比率 = 速动资产 / 流动负债（一般1:1为宜）
  - 现金比率 = (现金 + 现金等价物) / 流动负债

- **长期偿债能力**：
  - 资产负债率 = 负债总额 / 资产总额
  - 产权比率 = 负债总额 / 所有者权益
  - 利息保障倍数 = 息税前利润 / 利息费用

**营运能力指标**
- 应收账款周转率 = 营业收入 / 平均应收账款余额
- 存货周转率 = 营业成本 / 平均存货余额
- 流动资产周转率 = 营业收入 / 平均流动资产
- 总资产周转率 = 营业收入 / 平均资产总额

**盈利能力指标**
- 营业利润率 = 营业利润 / 营业收入
- 资产净利率 = 净利润 / 平均资产总额
- 净资产收益率 = 净利润 / 平均净资产
- 每股收益 = 净利润 / 普通股股数

### 第32章 政府会计

**政府会计的概念**
- 以货币为主要计量单位，对政府及事业单位的经济业务进行确认、计量、记录和报告

**政府预算会计要素**
- **预算收入**：政府会计主体在预算年度内依法取得并纳入预算管理的收入
- **预算支出**：政府会计主体在预算年度内依法发生并纳入预算管理的支出
- **预算结余**：预算收入减去预算支出后的余额

**政府财务会计要素**
- **资产**：政府会计主体过去的经济业务或事项形成的，由政府会计主体控制的，预期能够产生服务潜力或者带来经济利益流入的经济资源
- **负债**：政府会计主体过去的经济业务或事项形成的，预期会导致经济资源流出政府会计主体的现时义务
- **净资产**：政府会计主体资产扣除负债后的净额
- **收入**：报告期内导致政府会计主体净资产增加的、含有服务潜力或者经济利益的经济资源的流入
- **费用**：报告期内导致政府会计主体净资产减少的、含有服务潜力或者经济利益的经济资源的流出

**政府决算报告与政府财务报告**
- **政府决算报告**：综合反映政府会计主体年度预算收支执行结果的文件
- **政府财务报告**：反映政府会计主体特定日期财务状况和特定期间运行情况的文件

**政府综合财务报告和政府部门财务报告的区别**
- **政府综合财务报告**：以财政部门编制的合并报表为基础，反映一级政府整体财务状况
- **政府部门财务报告**：由各部门编制，反映本部门财务状况

### 第34章 物权法律制度

**物权法律制度的基本内容**
- **物权**：权利人依法对特定的物享有直接支配和排他的权利
- **物权法原则**：物权法定、一物一权、公示公信

**所有权**
- **概念**：所有人依法对自己的财产享有占有、使用、收益、处分的权利

**用益物权**
- **概念**：对他人所有的不动产或动产，依法享有占有、使用、收益的权利
- **类型**：土地承包经营权、建设用地使用权、宅基地使用权、地役权

**担保物权**
- **概念**：为确保债务履行，在债务人或第三人特定财产上设定的物权
- **类型**：抵押权、质权、留置权

**建设用地使用权**
- **取得方式**：出让、划拨
- **适用规则**：
  - 出让：有偿、有期限
  - 划拨：无偿、无期限（公益用途）
  - 住宅建设用地使用权期限届满自动续期

### 第35章 合同法律制度

**合同的概念**
- 民事主体之间设立、变更、终止民事法律关系的协议

**要约与承诺**
- **要约**：希望和他人订立合同的意思表示
  - 条件：内容具体确定、表明受约束
- **承诺**：受要约人同意要约的意思表示
  - 条件：由受要约人作出、与要约内容一致、在期限内作出

**合同的订立**
- 形式：书面、口头、其他形式
- 内容：当事人、标的、数量、质量、价款、履行期限、违约责任、争议解决

**合同的履行**
- 全面履行原则
- 诚实信用原则
- 抗辩权：同时履行抗辩权、先履行抗辩权、不安抗辩权

**合同的终止**
- 债务已按约定履行
- 合同解除
- 债务相互抵销
- 债务人依法将标的物提存
- 债权人免除债务
- 债权债务同归于一人

**合同的担保**
- 保证、抵押、质押、留置、定金

**合同的保全**
- 代位权：债务人怠于行使其到期债权，对债权人造成损害
- 撤销权：债务人放弃到期债权、无偿转让财产、以明显不合理低价转让财产

**合同的转让**
- 债权转让：通知债务人
- 债务转移：经债权人同意

**合同的变更**
- 当事人协商一致
- 法定变更事由

### 第36章 公司法律制度

**公司和公司法的概念**
- **公司**：依照中国法律在中国境内设立的有限责任公司和股份有限公司
- **公司法**：规范公司组织和行为的法律

**公司的特征和分类**
- **特征**：依法设立、以营利为目的、具有法人资格
- **分类**：
  - 有限责任公司：股东以出资额为限承担责任
  - 股份有限公司：股东以认购股份为限承担责任

**公司登记和企业信用信息公示**
- **公司登记**：设立登记、变更登记、注销登记
- **企业信用信息公示**：年度报告公示、即时信息公示

**公司设立**
- **条件**：股东符合法定人数、出资达到法定最低限额、制定公司章程、有公司名称和组织机构、有公司住所
- **程序**：名称预先核准 → 制定章程 → 缴纳出资 → 申请登记 → 领取营业执照

**公司组织机构**
- **股东会**：最高权力机构
- **董事会**：执行机构
- **监事会**：监督机构
- **经理**：日常经营管理

**股东权利**
- 表决权、分红权、知情权、优先认购权、剩余财产分配权

**董事、监事和高级管理人员**
- **任职资格**：无民事行为能力、经济犯罪、破产清算等情形不得担任
- **义务**：忠实义务、勤勉义务

**股份公司股份发行和转让**
- **股份发行**：同股同权、同股同价
- **股份转让**：自由转让，但发起人、董监高有限制

**公司变更**
- **合并**：吸收合并、新设合并
- **分立**：存续分立、解散分立
- **增资**：增加注册资本
- **减资**：减少注册资本，需通知债权人
- **解散**：章程规定、股东会决议、合并分立、吊销执照
- **清算**：成立清算组、清理财产、清偿债务、分配剩余财产

### 第37章 其他法律制度

**劳动合同法律制度**
- **劳动合同**：劳动者与用人单位确立劳动关系、明确权利义务的协议
- **订立**：书面形式、试用期规定
- **履行**：全面履行、协商一致变更
- **解除**：协商解除、劳动者单方解除、用人单位单方解除
- **终止**：合同期满、劳动者退休、死亡等
- **经济补偿**：按工作年限支付

**消费者权益保护法律制度**
- **消费者权利**：安全保障权、知情权、自主选择权、公平交易权、依法求偿权
- **经营者义务**：依法定或约定履行义务、听取意见、保障安全、提供真实信息、出具凭证、保证质量、售后服务
- **争议解决**：协商、调解、投诉、仲裁、诉讼
- **法律责任**：民事责任、行政责任、刑事责任

**反不正当竞争法律制度**
- **不正当竞争行为**：
  - 混淆行为
  - 商业贿赂
  - 虚假宣传
  - 侵犯商业秘密
  - 不正当有奖销售
  - 商业诋毁
  - 网络不正当竞争

- **监督检查**：县级以上市场监管部门
- **法律责任**：民事责任、行政责任
