新建硬盘分区作为交换分区
------------------------

硬盘分区情况

    设备            起点      末尾      扇区  大小 类型
    /dev/sda1       2048    821247    819200  400M Linux 文件系统
    /dev/sda2     821248   1640447    819200  400M Linux 文件系统
    /dev/sda3    1640448 840501247 838860800  400G Linux 文件系统
    /dev/sda4  840501248 871958527  31457280   15G VMware 诊断

把`/dev/sda4`作为交换分区 交换分区大小建议

  物理内存   不需要休眠   需要休眠   最大值
  ---------- ------------ ---------- --------
  256M       256M         512M       512M
  512M       512M         1024M      1024M
  1024M      1024M        2048M      2048M
  1G         1G           2G         2G
  2G         1G           3G         4G
  3G         2G           5G         6G
  4G         2G           6G         8G
  5G         2G           7G         10G
  6G         2G           8G         12G
  8G         3G           11G        16G
  12G        3G           15G        24G
  16G        4G           20G        32G
  24G        5G           29G        48G
  32G        6G           38G        64G
  64G        8G           72G        128G
  128G       11G          139G       256G

archlinux的wiki中建议交换分区类型为82 安装交换分区`mkswap /dev/sda4`
启用交换分区`swapon /dev/sdxy` 设置自动启动
在文件`/etc/fstab`中添加`UUID=<UUID> none swap defaults 0 0`
其中UUID`lsblk -no UUID /dev/sda4`
