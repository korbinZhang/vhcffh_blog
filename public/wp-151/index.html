python的整除

Jake G May 11, 2020 [编程] #python

python可以通过//进行整除运算 例如：

4//2
# 2
5//2
# 2
# 去尾法

当遇到负数时，最后的结果向下取整数 此时负号运算级高，先构成负数，再除法

-4//2
# -2
-5//2
# -3
-1//2
# -1

如果是减号，就先计算除法

-1//2
# -1
1-1//2
# 1
